# قالب لاتک (LaTeX) پروپوزال دانشگاه خوارزمی
### دانشکده فنی و مهندسی -- پرسشنامه طرح پیشنهادی پایان‌نامه کارشناسی ارشد

این قالب به طور اختصاصی بر اساس آخرین نسخه رسمی فایل ورد (`.doc`) دانشگاه خوارزمی و نمونه پروپوزال‌های تاییدشده طراحی شده است و به صورت کامل از بسته قدرتمند `xepersian` و فونت‌های استاندارد فارسی پشتیبانی می‌کند.

---

## راهنمای رفع خطای اورلیف (Overleaf)

اگر در سایت اورلیف با خطای زیر مواجه شدید:
```text
! Fatal Package xepersian Error: Oops! can not use pdftex.
(xepersian) The xepersian package requires XeTeX.
```
**علت خطا:** موتور پیش‌فرض کامپایل در اورلیف `pdfLaTeX` است، در حالی که زبان فارسی و بسته `xepersian` منحصراً نیازمند موتور **XeLaTeX** هستند.

### راه‌حل (بسیار ساده):
1. در گوشه بالا-چپ صفحه اورلیف روی دکمه **Menu** کلیک کنید.
2. در بخش **Settings**، گزینه **Compiler** را از `pdfLaTeX` به **`XeLaTeX`** تغییر دهید.
3. در همان منو مطمئن شوید **Main document** روی `Proposal.tex` تنظیم شده باشد.
4. منو را ببندید و دکمه سبز **Recompile** را بزنید.

> **نکته:** در این قالب فایلی به نام `latexmkrc` قرار داده شده است که به صورت خودکار به اورلیف فرمان می‌دهد با `XeLaTeX` کامپایل کند.

## ساختار فایل‌های پروژه

پروژه به صورت کاملاً ماژولار و تفکیک‌شده طراحی گردیده است:

```
├── Proposal.tex               # فایل اصلی اجرا و فراخوانی بخش‌ها
├── latexmkrc                  # تنظیمات کامپایل خودکار با XeLaTeX در اورلیف
├── references.bib             # بانک مراجع به فرمت BibTeX
│
├── front/
│   ├── info.tex               # مشخصات دانشجو، اساتید، عنوان و گرنت (این فایل را ویرایش کنید)
│   └── template/
│       ├── cover.tex          # صفحه اول شامل لوگوی دانشگاه خوارزمی و جداول اداری
│       └── images/logo.png    # لوگوی باکیفیت دانشگاه خوارزمی
│
├── chapters/                  # متن بخش‌های مختلف پروپوزال
│   ├── 01_problem_definition.tex # ۱. تعریف مسئله
│   ├── 02_importance.tex         # ۲. ضرورت و اهمیت پژوهش
│   ├── 03_literature.tex         # ۳. تجارب گذشته و سوابق طرح در داخل و خارج
│   ├── 04_objectives.tex         # ۴. اهم اهداف پژوهش
│   ├── 05_methodology.tex        # ۵. روش تحقیق، فرضیات و نحوه اجرای طرح
│   ├── 06_requirements.tex       # ۶. تجهیزات / مصالح / داده‌ها / نرم‌افزارهای مورد نیاز
│   ├── 07_phases.tex             # ۷. خلاصه مراحل انجام پژوهش
│   ├── 08_timeline.tex           # ۸. پیش‌بینی زمانبندی مراحل پژوهش (گانت چارت ۱۲ ماهه)
│   └── 09_references.tex         # ۹. فهرست مراجع
│
└── styles/
    ├── common.tex             # بارگذاری بسته‌ها و تنظیم فونت‌ها
    ├── custom.tex             # ماکروها و تعاریف دلخواه کاربر
    ├── alg-fa.tex             # دستورات فارسی الگوریتم‌ها
    └── fonts/                 # فونت‌های استاندارد (B Nazanin, XB Yas, Times)
```

## نحوه سفارشی‌سازی

### ۱. مشخصات دانشجو و پایان‌نامه:
فایل `front/info.tex` را باز کرده و عنوان‌های فارسی/انگلیسی، نام دانشجو، شماره دانشجویی، رشته، و اساتید راهنما، مشاور و ناظر را ویرایش کنید.

### ۲. نوع / گرنت:
در فایل `front/info.tex`، با تغییر مقادیر زیر به `true` یا `false`، چک‌باکس مربوطه به صورت خودکار تیک می‌خورد:
```latex
\GrantAdaditrue          % عددی
\GrantAzmayeshgahifalse  % آزمایشگاهی
\GrantRouzanetrue        % روزانه
\GrantPardisfalse        % پردیس
```

### ۳. جدول گانت چارت (زمانبندی):
در فایل `chapters/08_timeline.tex`، جدول ۱۲ ماهه به همراه درصد وزنی قرار دارد. برای فعال کردن هر ماه در ردیف یک فعالیت، کافی است عبارت `\cellcolor{gray!40}` را در ستون آن ماه قرار دهید.

### ۴. درج مراجع:
مراجع در فایل `references.bib` به صورت استاندارد ذخیره شده‌اند. در متن با دستور `\cite{Balle2018}` می‌توانید به آن‌ها ارجاع دهید.
