برای اجرای دقیق این پژوهش، تجهیزات و امکانات زیر مورد نیاز است:

\begin{enumerate}[label=\arabic*-, leftmargin=1.5cm]
    \item پردازنده گرافیکی (\lr{GPU}) قدرتمند برای محاسبات سنگین تانسوری و آموزش شبکه عصبی.
    \item دسترسی و استفاده از مجموعه‌دادگان استاندارد و مناسب بینایی ماشین (نظیر \lr{Kodak} و \lr{Open Images}).
    \item استفاده از شبکه‌های از پیش آموزش‌دیده، کتابخانه‌ها و فریم‌ورک‌های یادگیری عمیق (\lr{PyTorch}).
\end{enumerate}
